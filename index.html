Source & limitations

This optional integration requests https://github-contributions-api.jogruber.de/v4/{username}?y=last. The service scrapes the contribution graph shown on public GitHub profiles; it is not an official GitHub API. It may be delayed, rate-limited, temporarily unavailable, or stop working if GitHub changes its page markup. Only display data returned and validated by the service. Private activity is not exposed, and this calendar is not proof of every kind of work. No access token is sent or stored.

SYSTEM NOTES

How the RPG works

API data: profile, public repositories, followers, following, stars, forks, and account creation date come from GitHub's public REST API.

Estimated XP: repos × 20 + stars × 5 + forks × 8 + followers × 3, capped to sensible UI ranges. This is a game score, not a GitHub metric.

Achievements: unlock only from returned public data or actions you explicitly complete locally.

Contribution calendar: an optional community API scrapes the public contribution graph. It can be delayed or unavailable and is not an official GitHub API.

Privacy: no access token is requested or stored. Daily quest completion lives in your browser's localStorage.
